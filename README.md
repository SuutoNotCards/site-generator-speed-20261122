A faster drop-in for make.fun's makefun-site 1.0.0. `solve.js` exports `run({site, templates, files})` and returns the same output tree as makefun-site's build, byte for byte. Templates compile to closures with names resolved ahead of time, template parts that read only per-site values (site, tags, recent) render once per build, and Markdown inline text is escaped in runs instead of one character at a time. Nothing is kept from one case to the next.

Entry for the bounty [Build a static site faster, 22 November 2026](https://make.fun/bounty/site-generator-speed-01-run-20261122).

## Run it

```sh
MAKEFUN_INPUT_DIR=<dir with cases.json> MAKEFUN_OUTPUT_DIR=<out dir> node main.ts
```
